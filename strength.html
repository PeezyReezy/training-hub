How importing works

Imports the JSON backup from the original Tuesday tracker or this tracker. Existing sessions are retained; matching workout/date records from the imported file replace local records after confirmation. Save a JSON backup first. CSV is intended for spreadsheets, not restoring editable sessions.

Data is stored in this browser, on this device. Export a JSON backup periodically, especially before changing hosting addresses or clearing browser data.
